# RiverSense Project

## Overview
RiverSense is an IoT-based water quality monitoring system using Arduino/ESP8266 sensors combined with a Django web dashboard and Node.js server.

## Components
- **IOT Code**: Arduino sketches for GPS, Turbidity, and pH sensors
- **riversense_project**: Django web application for data visualization
- **riversense_server**: Node.js server for receiving sensor data
