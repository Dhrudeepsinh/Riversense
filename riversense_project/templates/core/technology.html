Technology

Built on Cutting-Edge Open-Source Stack

Every component carefully selected for real-world Indian riverfront deployment — scalable, reliable and cost-effective.

AI / ML Core

Trash Detection

YOLOv8-medium trained on 801 annotated images of River water surface waste over 150 epochs on Tesla T4 GPU.

One Detection Class

Chosen for operational relevance — cleanup crews need density, not taxonomy.

Real-Time Inference <50ms

Processes CCTV frames or web cam at 20 FPS on GPU.

Rich Augmentation Pipeline

Mosaic, horizontal flip, HSV shifts, random erasing, MixUp, rotation, blur, CLAHE and more — ensuring robustness to murky water and lighting variation.

GPS-Tagged Detections

Each detection inherits GPS coordinates from fixed camera GIS mapping. Events stored in InfluxDB for heatmap rendering.
