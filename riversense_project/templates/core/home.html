Technology

Five-Layer System Architecture

Clear separation of concerns from physical data collection to end-user output — scalable, cloud-native, open-source.

1

Data Collection — Arduino · CCTV/Web cam · MQTT

IoT sensors stream pH, turbidity and water level. CCTV cameras feed video frames for detection.

2

Data Pipeline — Node-RED · InfluxDB · AWS IoT Core

MQTT message broker routes time-series sensor data to InfluxDB. AWS IoT Core handles cloud ingestion.

3

AI / ML Engine — YOLOv8m · LSTM · Python · PyTorch

YOLOv8 detects floating trash at <50ms. LSTM predicts water levels 72h ahead using weather data.

4

Output Systems — Django · GIS Dashboard · SMS Alerts

Web dashboard displays live heatmaps, sensor gauges and detection events. Priority alerts via SMS.

5

Admin Panel — FastAPI · PostgreSQL · MongoDB

Compliance reports, incident management, detection log and operator access control for AMC/SRFDCL.
